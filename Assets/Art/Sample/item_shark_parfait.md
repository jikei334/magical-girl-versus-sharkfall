# item_shark_parfait（サメパフェ）

`item_shark_parfait.glb` / `.blend`

サメ1匹がそのままパフェになった小物（アイテム）です。胸びれより下がグラス、胸びれより上が中身（クリーム）、背中にウエハースのチェーンソーが刺さっています。

## 見た目
- 胸びれより下（胴の下半分〜尾）: 透明なパフェグラス。先が細くなる鉢の下に脚と丸い台座が付く。尾びれ・背びれはウエハース
- グラスの中身は4層: 青い半透明ゼリー（サメ形のグミ5匹入り）→ 白いクリーム → サメ肌の青灰色クリーム → 水色クリーム
- 胸びれより上（頭〜胴の上半分）: グラスの縁からあふれるクリーム。背中は青、お腹は白。目、エラ（左右5本）、歯が並んだ赤い口
- 胸びれ: 青（クリーム側）
- 背中: ウエハースで作ったチェーンソー（エンジン部・持ち手・ガイドバー・チェーンの刃）が斜め後ろ上向きに差さっている。ウエハース色の2トーン
- マテリアル: Glass / Jelly（この2つが半透明）/ CreamWhite / CreamGray / CreamLightBlue / Gummy / SharkBlue / SharkBelly / Fin / WaffleA / WaffleB / Teeth / Mouth / Eye（14種）

## サイズ・軸
- 高さ 約0.38m、幅 約0.235m（胸びれの端から端）、奥行き 約0.185m（チェーンソーの先を含む）。人間モデル（身長約1.7m）に対する実寸なので、アイテムとして見せたい場合はUnity側でスケールを上げてください。
- 原点は台座の底の中心（床に置くとちょうど接地）。
- 顔（口・目）は −Y（Blender）側＝正面に向いています。背びれとチェーンソーは +Y（後ろ）側です。

| 軸 | Blender | glb（Unity取り込み前） |
|---|---|---|
| 右 | +X | +X |
| 上 | +Z | +Y |
| 奥 | +Y | −Z |

アニメーションはありません。半透明（Glass / Jelly）はUnity側のシェーダーが透明対応（Fade/Transparent）になっているか確認してください。
