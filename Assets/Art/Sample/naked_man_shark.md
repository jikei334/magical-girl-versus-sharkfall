# naked_man_shark.glb

全裸中年男性シャーク(`Man` + `Shark` + `Mist`、リグ `ManSharkRig`)。FPS = 24。

遠くでは、股間にもやがかかった普通の中年男性。近づくにつれて股間から生えたサメが大きくなり、もやが晴れ、男性は後ろにのけぞってサメの尾びれになる。

## 方向の対応(Blender → glb: +Y→−Z, +Z→+Y, +X→+X)

| 方向 | Blender | glb |
|---|---|---|
| 男性の正面 / サメの進行方向(頭) | −Y | +Z |
| 背面 / 男性の背中側 | +Y | −Z |
| 上 | +Z | +Y |
| 男性の左(L) | +X | +X |

- 原点は男性の足元。サメの尾の付け根=男性の股間(Blender (0,−0.02,0.90) / glb (0,0.90,0.02))。
- サメ最大サイズ(sh_root スケール1)で全長約4.6、最大太さ約1.4。男性の身長は約1.8。
- ボーン: root, hips, spine, neck, head, 腕/脚(.L/.R)、sh_root(サメ全体のスケール用), sh0–sh3(体幹。左右のうねりは軸2、上下は軸0), sh_dorsal, sh_pecL/R, sh_jaw(下顎。軸0を負に回すと口が開く), mist_a/b/c(もや)
- サメの大きさは `sh_root` のスケール、もやの大きさは `mist_*` のスケールで制御(全クリップが毎回キーを持つ)。
- もや(`Mist`)は半透明マテリアル(alpha 0.55)。

## Unityでの使い方(目安)
`Reveal` は距離に応じて再生位置を決める想定。Animatorで Speed を0にし、Motion Time(normalized time)に `1 - clamp01((distance - near) / (far - near))` を渡す。遠距離は `Idle`、完全に近づいたら `Swim` に切り替える。
