# naked_man_head_shark.glb

全裸中年男性シャーク【頭部型】(`Man` + `Shark`、リグ `ManSharkRig`)。FPS = 24。局部型(naked_man_shark.glb)と同じ男性・同じボーン構成で、サメの生える場所と最終形が違う。もや(Mist)は無い。

遠くでは普通の全裸中年男性。近づくと頭がふくらんで震え、頭が縮んで消えて、首元からサメが真上(Z軸方向)に生える。サメが生えきったら(男性の首がしっぽの後ろに来る)、サメが上でUターンするように倒れ込んで降りてきて、Y軸に平行になる。男性もしっぽの後ろで同じくY軸に平行(うつ伏せ)になり、そのまま揺れる。

## 方向の対応(Blender → glb: +Y→−Z, +Z→+Y, +X→+X)

| 方向 | Blender | glb |
|---|---|---|
| サメの進行方向(頭) / 最終形で男性の頭側 | −Y | +Z |
| 最終形で男性の足側(しっぽの後ろ) | +Y | −Z |
| 上 | +Z | +Y |
| 男性の左(L)(立っているとき) | +X | +X |

- 原点は男性の足元(立っているとき)。サメの尾の付け根=男性の首元。`sh_root` は `neck` の子。
- サメ最大サイズ(sh_root スケール1)で全長約4.6。男性の身長は約1.8。
- 変身後(Swim)は、足が地面についた状態。`root`は軸0 = 0.65rad(約37°)で、位置は Blender (0, −2.0, 0)(glb (0, 0, +2.0))。男性の腰・背・首が計約53°前に曲がってサメの尾の付け根につながり、サメは水平。サメの胸ビレは地面すれすれ。Revealで前方に飛び出した先の位置。
- `sh_root` の軸0はπ/2(真上)で全クリップ共通(サメは隠れているクリップでも同じ)。
- 背びれ(`sh_dorsal`)は `sh2` の子(体を折り曲げたときに背びれが体から浮かないようにするため)。
- サメの大きさは `sh_root` のスケール、頭の大きさは `head` ボーンのスケール(0.001で非表示)。全クリップが毎回キーを持つ。

## Unityでの使い方(目安)
`Reveal` は距離に応じて再生位置を決める想定(Animator Speed 0 + Motion Time)。遠距離は `Idle`、完全に近づいたら `Swim` に切り替える。Reveal中に`root`が持ち上がるので、Unity側のオブジェクト原点は足元のまま使い、Rootモーションは無効にしておく。
