# naked_man_back_shark.glb

全裸中年男性シャーク【背中型】(`Man` + `Shark` + `Crack`、リグ `ManSharkRig`)。FPS = 24。局部型・頭部型・腕型と同じ男性・同じ歩きアニメ。もや(Mist)は無い。

普通の全裸中年男性だが、近づくと前かがみになって震え、背中が裂けて、そこからセミの羽化のようにサメが生まれる。サメは背中から上へ伸び、後ろへ反り返ったあと、尾が背中から抜けて前向きに起き上がり、男性の頭上へ飛び立つ。抜け殻になった男性は力が抜けてひざをついたままになる。

## 方向の対応(Blender → glb: +Y→−Z, +Z→+Y, +X→+X)

| 方向 | Blender | glb |
|---|---|---|
| 男性が向く方向・サメの頭 | −Y | +Z |
| 男性の背中・サメの尾 | +Y | −Z |
| 上 | +Z | +Y |

- 原点は男性の足元。男性は原点付近に残り、サメは完成後に原点から Blender +Y 側へ2.4mずれた位置、高さ約3m(尾の付け根)で水平に浮かぶ(頭は −Y 向きで、男性の真上に重なる)。
- サメ(`Shark`、ボーン `sh_root`, `sh0`–`sh3`, `sh_jaw`, `sh_pecL/R`, `sh_dorsal`、全長約4.6m)は、男性の骨とは別の `shark_pivot`(`root` の子、尾の付け根の位置)の下にぶら下がっている。**サメの位置・向き・大きさはすべて `shark_pivot`** が持つ(男性の背中から離れても、そのまま動かせる)。他のクリップではサメは `sh_root` のスケール0.001で非表示。
- `Crack`(背中の黒い裂け目。ボーン `crack` が背骨 `spine` の子)。Reveal で現れ、サメが育つとともに少し広がる。Swim では出たまま。Idle / Walk / WalkSpin ではスケール0.001で非表示。
- 全クリップが全チャンネルのキーを持つ。Unity側はRootモーションを無効にして使う。

## Unityでの使い方(目安)
`Reveal` は距離に応じて再生位置を決める想定(Animator Speed 0 + Motion Time)。遠距離は `Idle`、完全に近づいたら `Swim` に切り替える。サメが背中から飛び立つ前後で男性の位置は変わらない。

## Climbクリップの使い方
その場で動くクリップ(位置は動かない)。男性は壁に腹を向けた向き(glb上では +Z 方向を向く)で、上方向は +Y。ゲーム側で、壁の面に合わせてオブジェクトを置き、上へ移動させる。速さの目安は約0.5〜0.8m/秒(足がすべって見えるなら移動速度を調整する)。
