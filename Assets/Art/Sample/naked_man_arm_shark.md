# naked_man_arm_shark.glb

全裸中年男性シャーク【腕型】(`Man` + `Shark` + `SharkB` + `SharkC`、リグ `ManSharkRig`)。FPS = 24。局部型・頭部型と同じ男性・同じ歩きアニメ。もや(Mist)は無い。

普通の全裸中年男性だが、近づくと競泳選手の飛び込みのように跳び上がって前に倒れ、両腕を前に伸ばしたアンパンマンの飛行状態になる。両手の先からサメの頭が生えて、手の方から体の方へ大きく育ちながら男性の体を飲み込み(男性の体は一度ふくらんでからサメの中に隠れる)、最後は頭が2つで体が1つのサメ(双頭ザメ)になって飛ぶ。2つの頭は腰の上の1本の胴体につながる。

## 方向の対応(Blender → glb: +Y→−Z, +Z→+Y, +X→+X)

| 方向 | Blender | glb |
|---|---|---|
| 進行方向(サメの頭) | −Y | +Z |
| 後ろ(サメの尾) | +Y | −Z |
| 上 | +Z | +Y |
| 左の頭(`Shark`) | +X側 | +X側 |
| 右の頭(`SharkB`) | −X側 | −X側 |
| 胴体(`SharkC`) | 中央 | 中央 |

- 原点は男性の足元(立っているとき)。飛行後は原点から Blender −Y 方向に約3m進んだ位置、高さ約2m(骨盤の位置)で止まる。`root` ボーンが位置・向きを持つので、Unity側はRootモーションを無効にして使う。
- 双頭ザメは3パーツのメッシュで、継ぎ目が見えないよう作ってある。左の頭(`Shark`)、右の頭(`SharkB`、ボーン名に `b_` を付ける)、胴体(`SharkC`、ボーン名に `c_` を付ける。背びれ・胸ビレ・三日月形の尾びれ(`c_sh0` に付く)を持つ)。胴体の前部は断面が「ひょうたん形(2つの首)」に変形してあり、その切り口が2つの頭の付け根の断面とぴったり重なる。頭は完成形で平行に並び、V字には開かない。
- スケール: 頭は最終1.7、胴体は1.2。全長は約6.4m。
- 左右の頭は `sk_L` / `sk_R`、胴体は `sk_C` の下にぶら下がっている(いずれも鼻先の位置のボーン)。**大きさは各 `sk_*` のスケール**。頭の付け根は成長が終わると胴体の前面と一致し、成長の途中では手から生えて横に開いていく。`sk_L` / `sk_R` の位置・向きは胴体(`sk_C`)に追従するよう計算済みで、Swim 中も継ぎ目がずれない(位置のキー値は親の手のスケール0.001のため大きい数値になる)。
- 継ぎ目を保つため、頭の首ボーン(`sh1`–`sh3`)と胴体前部(`c_sh1`–`c_sh3`)の横振りは無し。うねりは尾(`c_sh0`)だけ。
- 男性の体のふくらみは `hips`, `spine`, `neck`, `thigh.L/R` の横幅スケール(軸0・2)で表現。`head` と `hand.L/R` は、サメに隠れる時期にスケール0.001で非表示。
- 全クリップが全チャンネルのキーを持つ。

## Unityでの使い方(目安)
`Reveal` は距離に応じて再生位置を決める想定(Animator Speed 0 + Motion Time)。遠距離は `Idle`、完全に近づいたら `Swim` に切り替える。
